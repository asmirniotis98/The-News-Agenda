# The-News-Agenda
The News Agenda: track how terms trend in Greek news coverage (ΑΠΕ-ΜΠΕ, 2011–2026), detect peaks, and get LLM summaries of what happened at each peak.

Ο κώδικας διατίθεται με άδεια MIT. Τα δεδομένα προέρχονται από το glossAPI/amna-press (ΑΠΕ-ΜΠΕ) και υπόκεινται στην άδεια CC BY-NC-ND 4.0.
