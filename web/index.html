Ενεργοποίηση συνόψεων

Οι συνόψεις γράφονται από γλωσσικό μοντέλο και κάθε νέα σύνοψη έχει κόστος. Επιβεβαιώστε ότι δεν είστε ρομπότ τικάροντας το κουτί.

Το δικό σας κλειδί Claude API

Οι συνόψεις που υπάρχουν ήδη εμφανίζονται χωρίς κλειδί. Για νέες συνόψεις χρειάζεται το δικό σας κλειδί από το Anthropic Console· το κόστος (περίπου $0,001 ανά σύνοψη) χρεώνεται σε εσάς.

  • Δεν αποθηκεύεται πουθενά: κρατιέται μόνο στη μνήμη του server και σβήνεται σε 30 λεπτά (ή αν απενεργοποιήσετε τις συνόψεις).
  • Λειτουργεί μόνο από τη σημερινή σας σύνδεση (IP). Αν αλλάξει, θα το ζητήσουμε ξανά.
  • Στέλνεται μόνο στο Anthropic. Προτείνουμε ξεχωριστό κλειδί με όριο χρέωσης, που θα ανακαλέσετε μετά.
